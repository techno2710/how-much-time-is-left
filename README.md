# How much time is left?

Zeigt, wie viele Schultage (Niederösterreich, 2026/27) bis zur RDP noch übrig sind.

- Zeitraum: 07.09.2026 bis 30.04.2027 (verkürztes Schuljahr wegen der RDP)
- Gezählt werden nur Schultage (Montag bis Freitag). Ferien, Feiertage und schulfreie Tage zählen nicht.
- Jeder Schultag ist ein Punkt, eine Figur springt jeden Tag einen Punkt weiter.
- Drei Bahnen: Gesamt, aktueller Monat, aktuelle Woche.

## Anpassen

Alle freien Tage stehen oben in `script.js` in `FREE_PERIODS`. Schulautonome Tage der eigenen Schule
können in `SCHOOL_AUTONOMOUS_DAYS` eingetragen werden, die Zähler passen sich automatisch an.
